1️⃣ Grafični simulator

🖥️ Simulator

Vstop v aplikacijo

Pot do aplikacije
HOME → Apps → Statistics → Stat 2 Var
Opis

Ko odprete Stat 2 Var, se prikaže tabela s stolpcema x in y. To je glavna podatkovna mreža.

Prvi koraki
  1. Pritisnite APPS
  2. Izberite Statistics
  3. Kliknite na Stat 2 Var
  4. Vidite tabelo s podatki
📍 Prikaz točk

Scatter prikaz (Razpršenost)

Pot v aplikaciji
Menu → Plot
Tehnični opis

Prikazuje vse podatkovne pare kot točke na 2D grafu. Os X je neodvisna, os Y je odvisna spremenljivka.

Kaj vidite:
Rdeče ali modre točke na grafu
Kaj pomeni:
Redke točke = razpršeni podatki
Guste točke = povezane spremenljivki
📈 Linija

Linearna črta (Fit)

Pot v aplikaciji
Menu → Fit → Linear
Kaj se zgodi

HP Prime izračuna linearno funkcijo y = a·x + b, ki najbolje opisuje podatke. Črta se nariše čez točke.

Formula: y = 1.8x + 2.4 (primer)

R²: Pove, kako dobro črta ustreza podatkom (0–1, bliže 1 je bolje)

🎯 Predpovedovanje

Napoved točke

Pot v aplikaciji
Menu → Predict
Kako se uporablja

Ko imate model (npr. y = 1.8x + 2.4), lahko vnesete x in dobite y.

Primer: x = 10 → y ≈ 20.4

3️⃣ Uvod in osnove

📚 Osnove

Kaj je Stat 2 Var (dvovariabilna statistika)

Definicija

To je analiza dveh spremenljivk (x in y). Cilj je razumeti, kako je ena spremenljivka odvisna od druge.

Primeri iz prakse
  • 💰 Prodaja glede na mesec
  • 🌡️ Poraba energije glede na temperaturo
  • 📈 Cena lastninskega premoženja glede na velikost
  • 🏃 Čas tekma glede na razdaljo
🎯 Koncept

Neodvisna (x) in odvisna (y) spremenljivka

Razlika
x (neodvisna)
Vhodna vrednost
Ki jo vi izbirate
y (odvisna)
Izhodna vrednost
Ki se spreminja
Primer 
x = čas (ure)
y = razdalja (km)
🔍 Razumevanje

Pare podatkov (x, y)

Struktura

Vsaka vrstica v tabeli je en par: ena vrednost x in ena vrednost y.

Vrstica 1: x=1, y=2
Vrstica 2: x=2, y=4
Vrstica 3: x=3, y=5
💡 Nasveta: Več kot je parov, bolj natančen je model.

📊 Korelacija

Koeficient korelacije

Formula 
Corr(x, y)
Pomen rezultata
Vrednost Pomen
1 Popolna pozitivna povezava
0.7 - 0.9 Močna pozitivna
0.3 - 0.7 Srednja povezava
0 Ni povezave
-1 Popolna negativna
📈 Regresija

Linearna regresija - izračun

Model 
y = a·x + b
HP Prime izračuna 
a = naklon (slope)
b = prestrezanje (intercept)
R² = koeficient determinacije
HP Prime avtomatično izračuna a in b. Vi samo pritisnete Fit!
📐 R²

Koeficient determinacije (R²)

Kaj pove 
R² = (0 do 1)
R² = 1: Model popolnoma ustreza
R² = 0.9: Odličen model
R² = 0.7: Dobar model
R² = 0.5: Sprejemljiv model
R² < 0.5: Slab model
⚠️ Nikoli ne uporabljajte modela z R² < 0.7 za napovedovanje!
🎯 Napoved

Kako napovedati y

Postopek
  1. Imate model: y = 1.8x + 2.4
  2. Vnesete x = 10
  3. HP Prime izračuna: y = 1.8·10 + 2.4 = 20.4
x = 10 → y ≈ 20.4

9️⃣ Delovni postopki (Korak za korakom)

✅ Postopek

Faza 1: Vnos podatkov

Kaj naredite
  1. Pritisnite APPS → Statistics → Stat 2 Var
  2. V tabeli vnesite pare x, y
  3. Vsaka vrstica = en par
Primer:
x: 1  2  3  4  5
y: 2  4  5  7  9
Nasveta

Pazite na napake pri vnosu! Eno napačno število lahko preusmeri ves model.

✅ Postopek

Faza 2: Pregled podatkov

Kaj preverite
  • Ali so vsi x različni (ali so enaki)?
  • Ali je y smiselna glede na x?
  • Ali so izstopajoče točke?
Menu → Data → Statistics (prvo povzetek)
✅ Postopek

Faza 3: Grafični pregled

Kaj naredite

Pritisnite Menu → Plot → Scatter

Poglejte obliko razpršenosti:

  • 💧 Linearna (ravna črta) → Linear fit
  • ∿ Ukrivljena (parabola) → Quadratic fit
  • 📈 Eksponentna (hitro raste) → Exponential fit
✅ Postopek

Faza 4: Izbira modela

Odločitev

Pritisnite Menu → Fit in izberite:

Linear
Če je trend raven
Quadratic
Če je ukrivljen

HP Prime avtomatično izračuna a, b in R²

✅ Postopek

Faza 5: Preverjanje modela

Ali je model dobar?

Pritisnite Menu → Results

  • Če je R² > 0.9 → odličen model ✅
  • Če je R² > 0.7 → dobar model ✅
  • Če je R² < 0.5 → slab model ❌
Pred napovedovanjem VEDNO preverite R²!
✅ Postopek

Faza 6: Napoved

Kako napovedati

Pritisnite Menu → Predict

Vnesite x in dobite y:

Vnesete: x = 10
Dobite: y = 18.4
Napoved je natančna samo, če je R² > 0.7!

🔟 Primeri in napovedovanje

📊 Primer 1

Prodaja po mesecih

Podatki 
Mesec: 1  2  3  4  5
Prodaja: 12 14 17 20 22
Postopek
Fit → Linear
Rezultat 
y = 2.5x + 9.5
R² = 0.99 ✅ odličen
Napoved za mesec 7 
y = 2.5·7 + 9.5 = 27
📊 Primer 2

Razdalja in čas (fizika)

Podatki (pospešeno gibanje) 
Čas (s): 0  1  2  3  4
Razdalja (m): 0  1  4  9  16
Postopek
Fit → Quadratic
Rezultat 
y = x² (formula pospešenega gibanja!)
R² = 1.0 ✅ popolno
📊 Primer 3

Temperatura in poraba energije

Podatki 
Temp (°C): -5  0  5  10 15
Poraba (kW): 45 35 25 15 8
Postopek
Fit → Linear
Rezultat 
y = -3.5x + 17.5
R² = 0.99
Napoved pri 20°C 
y = -3.5·20 + 17.5 = -52.5 ❌ (nesmisleno! Model velja samo do 15°C)
📊 Primer 4

Rast rastline (eksponentna)

Podatki 
Dan: 1  2  3  4  5
Višina (cm): 2 4 8 16 32
Postopek
Fit → Exponential
Rezultat 
y = 2·2^x (ali y = a·e^(bx))
R² = 1.0
Napoved za dan 6 
y = 2·2^6 = 128 cm

1️⃣1️⃣ HP Prime sintaksa in koda

💻 Koda

Program: Vnos podatkov

HPP Program
EXPORT StatDemo() BEGIN LOCAL x, y; x := [1,2,3,4,5]; y := [2,4,5,7,9]; PRINT(x); PRINT(y); END;
Kaj se zgodi

Program ustvari dve listi in ju izpiše na zaslonu.

💻 Koda

Program: Linearna regresija

HPP Program
EXPORT LinearReg() BEGIN LOCAL x, y, a, b, r2; x := [1,2,3,4,5]; y := [2,4,5,7,9]; // Izračun naklona in prestrezanja a := 1.7; // nagib b := 0.5; // prestrezanje PRINT("y = " + a + "x + " + b); END;
Opomba

V pravi aplikaciji bi HP Prime avtomatično izračunal a in b.

💻 Koda

Program: Napoved

HPP Program
EXPORT Predict() BEGIN LOCAL x0, y0, a, b; a := 1.7; b := 0.5; x0 := 10; y0 := a*x0 + b; PRINT("x = " + x0); PRINT("y = " + y0); END;
Izhod 
x = 10
y = 17.5
💻 Koda

Program: Prikaz grafa

HPP Program
EXPORT PlotDemo() BEGIN LOCAL x, y; x := [1,2,3,4,5]; y := [2,4,5,7,9]; // Prikaz točk PLOT(x, y, 2, RED); // Prikaz modelne črte PLOT(1.7, 0.5, 1, BLUE); END;
Kaj se zgodi

Prikaze rdeče točke in modro linijo na grafu.

💻 Koda

Program: Statistika

HPP Program
EXPORT StatsCalc() BEGIN LOCAL x, m, s; x := [1,2,3,4,5]; m := Mean(x); s := StdDev(x); PRINT("Mean = " + m); PRINT("StdDev = " + s); END;
Izhod 
Mean = 3
StdDev = 1.41

✅ Preverjanje

Pred napovedovanjem

Kaj preveriti
  • ✅ Podatki so pravilni?
  • ✅ Trend je viden na grafu?
  • ✅ Model je izbran pravilno?
  • ✅ R² > 0.7?
  • ✅ Napoved je smiselna?
💡 Končni nasveti:
  • Vselej začnite s pregledom podatkov in grafa.
  • Ne sprejmite modela le zato, ker obstaja — preverite R².
  • Korelacija ≠ vzrok in posledica. Statistika samo opisuje.
  • Napoved je dobra samo, če je R² > 0.7.
⚠️ Pogosta opozorila:
  • Ne uporabljajte linearne regresije, če je trend jasno kvadraten.
  • Izstopajoče točke lahko uničijo model — jih odstranite.
  • Napoved zunaj območja podatkov je nevarna.
